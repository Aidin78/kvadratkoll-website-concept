# Kvadratkoll redesign

An unofficial redesign concept and portfolio project for Kvadratkoll.se, a Swedish property measurement service. This is **not** the official Kvadratkoll website.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS v4, lucide-react.

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
```

## Scripts

| Command             | Description                              |
| ------------------- | ---------------------------------------- |
| `npm run dev`       | Start the dev server                     |
| `npm run build`     | Production build                         |
| `npm run start`     | Serve the production build               |
| `npm run lint`      | ESLint                                   |
| `npm run typecheck` | Generate route types and run `tsc`       |
